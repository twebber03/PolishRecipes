FSP Team 5 - Written Plan 


Navigation bar
* FSP
* Home
* Discover
* Saved
* Search


FSP
* Name of the application
* About us section
* About the website section
* About our motivation section


Home page
* Displays top k dishes on a carousel 
* Top k dishes are based on weights (how often people click on the dish)
* Pressing the right arrow moves on to the next k dish
* Pressing the left arrow moves on to the previous k dish
* Only displays dish images and the current dish title


Search
* Search bar where user can type
* Autocomplete shows up when user is typing
* Tags can be selected to filter search results
* Shows top k dishes for that search
* Shows any additional search results below


Discover
* Displays bottom k dishes on a carousel
* Pressing the right arrow moves on to the next k dish
* Pressing the left arrow moves on to the previous k dish
* Only displays dish images and the current dish title


Individual Dish
* When a dish image is clicked, this page shows up for each dish
* This page displays the name, picture, location, ingredients, recipe and culture of the dish
* Dishes are able to be favorited with the button next to the dish name


Saved
* User’s favorite dishes show up on this page
* Favorite dishes are grouped and displayed by the date the user saved them on
